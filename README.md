# 🎧 AudioFlux — Music Player UI

Interface web inspirada em plataformas modernas de streaming de música, com visual futurista e foco total em **experiência do usuário**.

---

## ✨ Visão Geral

O **AudioFlux** é um projeto Front-End desenvolvido para demonstrar habilidades em **UI Design** e **Web Development**, combinando estética **cyberpunk**, layout moderno e boas práticas de organização de código.

---

## 🛠️ Tecnologias Utilizadas

- HTML5  
- CSS3  
- Tailwind CSS  
- Google Fonts  
- Material Symbols Icons  

---

## 🎨 Destaques do Projeto

- 🎧 Interface dark moderna com efeitos neon  
- ⚡ Layout inspirado em players profissionais  
- 📂 Sidebar interativa  
- 🔍 Campo de busca no header  
- 🎵 Listagem de músicas estilizada  
- ⏯️ Player fixo com controles  
- 📱 Design responsivo
